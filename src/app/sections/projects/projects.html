OUT — Plataforma de experiencias y eventos

Desarrollador Backend Java · Nov 2024 – Enero 2025 out.com.ar ↗

OUT es un marketplace de experiencias donde los usuarios pueden descubrir eventos, comprar entradas para fechas específicas y recibir notificaciones desde aplicaciones web y mobile.

Problema a resolver

Diseñar y mantener una API backend robusta que soporte compras, pagos, notificaciones y gestión de usuarios, asegurando estabilidad en producción y capacidad de crecimiento.

Mi rol y responsabilidades

Fui responsable del desarrollo y mantenimiento del backend, trabajando junto a equipos de frontend y mobile, y manteniendo comunicación directa con el cliente para definir requisitos y validar avances.

Decisiones técnicas y aportes clave

  • Lógica de compra de entradas con fechas específicas y validaciones de consistencia.
  • Integración de pagos con Mercado Pago Checkout Pro y split de pagos.
  • Autenticación y autorización con JWT y gestión de roles.
  • Notificaciones push con Firebase Cloud Messaging (Android e iOS).
  • Gestión de imágenes en Amazon S3.
  • Pruebas unitarias con JUnit 5 y Mockito.
  • Refactorización para mejorar mantenibilidad y reducir deuda técnica.

Infraestructura y despliegue

Despliegue y mantenimiento en AWS utilizando EC2, RDS (MySQL) y administración básica mediante consola Linux.

Java · Spring Boot · MySQL · AWS · JWT · Mercado Pago · Firebase FCM · JUnit 5 · Mockito

Aprendizajes

Trabajar con un sistema real en producción me permitió entender la importancia del mantenimiento, la comunicación con el cliente y la calidad del código a largo plazo.
